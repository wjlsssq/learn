# 新增工程接入指南

本指南约定接入要求，不生成代码。每次根据用户提供的学习链路设计工程，选择适合的语言、框架和内部结构。

## 先明确本次目标

接入前记录：学习什么、解决什么场景、准备验证哪些正常和异常路径、需要哪些进程或外部资源。

优先判断是否可以扩展现有工程。当场景、生命周期或实验隔离需要独立边界时，建立新的 `projects/<project-id>/`。学习一种中间件不自动意味着需要新建完整前后端系统。

## 工程标识与结构

工程标识采用稳定、唯一的小写短横线名称，例如 `knowledge-assistant`。目录、门户登记、配置和文档使用同一标识。

工程内部按实际需要组织，例如：

```text
projects/knowledge-assistant/
├─ README.md              目标、运行、依赖、验证和文档入口
├─ web/                   需要界面时建立
├─ agent-service/         选择 Python 实现时建立
├─ java-service/          存在独立 Java 业务职责时建立
└─ docs/                  设计、接口、学习记录
```

以上是示例结构，不是当前已实现工程，也不是每个工程的必备目录。纯 Python 服务、Java 后端或多个协作服务均可接入。

## 接入步骤

1. 在 `projects/` 建立所属工程目录和 `README.md`，写清目标、范围及验收方式。
2. 选择当前需要的技术栈；建立可独立运行的入口，保留相应语言的工程习惯。
3. 明确依赖与配置。仅按需引入对应语言公共库；不得引用其他工程的内部业务实现。
4. 配置构建和测试。前端包加入 pnpm workspace 覆盖范围；Java 模块按需要加入 Maven 聚合；Python 工程维护自己的环境与依赖管理。
5. 为所有进程登记端口、启动命令和必要环境变量。一个工程的依赖缺失不应使无关工程无法启动。
6. 在 `portal/src/projects.ts` 的 `projects` 数组中新增条目，遵循同文件的 `ProjectDefinition` 类型；填写标识、名称、说明、源码路径、技术信息、文档标识与启动说明，通过 `entries` 声明可点击的实际工程入口，并同步相关测试。
7. 新增运行探测时声明健康接口、超时和访问方式。当前基础服务探测位于 `portal/src/App.vue`，新增异构工程时按真实协议增加适配；无需要求 Python 等工程实现 Spring Boot 的健康接口。没有探测能力的工程保持明确状态，不推断为在线。
8. 补充工程设计与开发文档，更新仓库 [PROGRESS.md](PROGRESS.md)，执行相关验证后提交并推送。

## 公共能力接入

Java 工程按需依赖 `shared/java/web-support`，通过 `@Import(WebSupportConfiguration.class)` 显式启用。业务错误码由所属工程维护，真实 HTTP 状态和请求关联约定保持一致。

Vue 工程可按需依赖 `@learn/http` 和 `@learn/ui`。请求客户端配置本工程的 `baseURL`、超时和取消策略，业务 API 封装与业务状态留在工程内部。`getJson` 的超时覆盖 JSON 读取；`request` 返回原始响应，超时覆盖收到响应头之前的阶段，后续下载或流式消费通过调用者的 `AbortSignal` 取消。

Python 工程当前没有预建公共包。有重复且稳定的需求时再提取 Python 公共能力；跨语言共享接口定义和配置约定，不直接复用 Java 类或实体。

## 数据与外部资源

只有出现持久化需求时才设计所属工程的数据模型和迁移。资源接入文档至少说明：用途、版本、启动方式、访问配置、数据归属与清理方法。

数据库、缓存、MQ、文件存储等应有明确的工程边界。测试、压测或故障实验需要可控的隔离范围；清理操作仅针对本工程所属资源。

## 最低验收清单

- [ ] 已记录学习目标、场景、范围和完成条件。
- [ ] 工程可以按照自己的文档独立启动、停止和验证。
- [ ] 依赖、端口和配置明确，实际凭据未提交。
- [ ] 门户入口有效；未运行或不可达时给出真实状态。
- [ ] 正常链路和重要异常路径有对应验证。
- [ ] 公共模块使用方式与依赖边界清楚。
- [ ] 受影响的既有工程仍能构建或运行。
- [ ] 已更新开发文档、当前进度及必要的架构决策。
- [ ] 提交与推送结果已核对；未执行的检查如实记录。

重复出现且步骤稳定的局部操作，未来可以评估脚本化；当前没有工程生成工具建设任务。
