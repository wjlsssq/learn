# 当前进度

本文件是仓库当前状态的唯一记录，更新日期为 2026-11-12（Asia/Shanghai）。

## 当前阶段

v0.1 最小工程底座已完成本地验收。门户、Java 基础服务、必要公共模块、扩展规则和文档维护机制已建立。登录权限、数据库、Redis、MQ、Agent、Python 实现、生成工具及在线部署不属于本阶段。

## 已完成能力

- Vue 门户：文件夹卡片、搜索、分类、排序、网格/列表、工程详情、命令复制、真实工程入口与仓库文档浏览。
- 前端公共模块：可配置 HTTP 客户端及基础样式变量。原始响应支持下载和流式读取，调用方在响应头返回后仍能取消流。
- Java 公共模块：参数校验、业务错误码、真实 HTTP 状态、安全错误结构、请求关联标识和 Servlet 错误派发处理。
- 独立基础服务：提供信息和健康检查，无数据库及中间件运行依赖。
- 工程规范：独立构建与启动、明确依赖方向、语言自选、按学习链路手动接入新工程。
- 协作流程：修改、验证、同步文档、提交并推送 origin main，用户已授权后续沿用。
- GitHub Actions：配置文件及官方 Action 标签已经核对；云端执行状态以对应提交的 Actions 结果为准。
